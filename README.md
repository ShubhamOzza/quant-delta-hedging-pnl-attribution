# Project I-10: Delta-Hedging Simulation and PnL Attribution

A complete, reproducible study of the economics of a delta-hedged short
at-the-money straddle: Black-Scholes pricing and Greeks, a self-financing
discrete hedging engine with cash accounting, step-by-step PnL attribution,
vol-mismatch and hedging-frequency experiments, transaction-cost breakeven
analysis, and a real-data rolling straddle workflow.

## Quick start

```bash
pip install -r requirements.txt

# Synthetic GBM demo (validates the engine and the theory)
python Delta_Hedging_PnL_Attribution.py --mode demo

# Real-data rolling straddle study (CSV)
python Delta_Hedging_PnL_Attribution.py --mode real --csv your_prices.csv

# Real-data rolling straddle study (yfinance)
python Delta_Hedging_PnL_Attribution.py --mode real --ticker SPY \
    --start 2020-01-01 --end 2025-01-01
```

All outputs are written to `outputs_demo/` or `outputs_real/` next to the
script (override with `--outdir`). The demo takes roughly a minute with the
default 1,500 paths per experiment.

## Real-data mode outputs (in `outputs_real/`)

The repository ships a real-data run on SPY, 2020-01-02 to 2024-12-31 (1,258 daily
closes, 1,215 rolling straddle episodes), downloaded live via yfinance.

| File | Contents |
|---|---|
| `real_rolling_straddle_by_episode.csv` | One row per rolling 1-month straddle: PnL, attribution, vols, variance risk premium |
| `real_rolling_straddle_summary.csv` | Aggregate statistics, including the OLS regression of PnL on the variance risk premium (slope, R-squared, p-value) and the PnL-sign-match rate |
| `fig5_real_rolling_straddle.png` | Episode PnL and vol time series |
| `fig6_real_vrp_regression.png` | Scatter of episode PnL versus the variance risk premium with the fitted regression line |

On this SPY sample, the regression slope is 36.4 (R-squared 0.42, p below 1e-140),
and 89.1% of episodes have hedged PnL whose sign matches the sign of the variance
risk premium (implied minus realized variance), the real-data confirmation of the
same mechanism validated in the synthetic demo.

## Input data schema (real mode)

CSV file with case-insensitive headers:

```
date,close
2020-01-02,324.08
2020-01-03,322.41
...
```

- `date`: any format pandas can parse.
- `close`: daily closing price of the underlying (adjusted closes preferred).
- Extra columns are ignored. At least 60 observations are required; five years
  (about 1,260 trading days) is the intended scale.

## Command-line options

| Flag | Default | Meaning |
|---|---|---|
| `--mode {demo,real}` | demo | synthetic experiments or real-data study |
| `--csv PATH` | none | CSV input for real mode |
| `--ticker SYMBOL` | none | yfinance ticker for real mode (e.g. SPY, ^GSPC) |
| `--start`, `--end` | 2020-01-01, 2025-01-01 | yfinance download window |
| `--outdir PATH` | outputs_<mode> | output folder |
| `--paths N` | 1500 | GBM paths per demo experiment |
| `--rate R` | 0.02 | risk-free rate in the real-data study |
| `--tc-bps K` | 1.0 | transaction cost in bps in the real-data study |

## Dependencies

- Python 3.9+
- numpy, pandas, matplotlib, scipy
- yfinance (optional; only needed for `--mode real --ticker`)

## Notes and limitations

- Demo mode uses simulated geometric Brownian motion paths. Demo numbers are a
  controlled validation of the engine and the theory, not real market evidence.
- Real mode uses lagged 21-day realized volatility as a proxy for implied vol
  because option quote data is not included; read absolute PnL levels as
  illustrative and focus on the variance-gap relationship.
- The hedge is delta-only by design; gamma and vega risk are the object of
  study, not hedged away.
- Losses on the hedged book are realistic hedging outcomes (realized variance
  above implied), not numerical errors; the accounting consistency check
  guarantees the books close to machine precision.
